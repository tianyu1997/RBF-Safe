# 持久安全记忆与车队协调（v5.0）

> 英文原文：[Persistent safety memory and fleet coordination](../../../assurance/memory/safety-memory.md)

`RBFSafe::memory` 是几何、规划、审核、shield 和学习层产物的持久目录。它管理身份和生命周期，不重新解释其他格式的字节，也不提升产物证据等级。

`MemoryArtifact` 绑定类型、部署、机器人、场景、任务、内容 SHA-256、定位符、证据等级和标签。复用查询要求精确身份或显式允许的跨任务关系，并返回 `DIRECT`、需要复验或不兼容等处置。

车队快照和预留使用部署 ID、机器人摘要、场景摘要、时间窗和保守工作空间包络。`analyze_fleet_schedule` 只在调用方声明的包络下报告冲突/分离，不证明真实机器人轨迹或网络协调。

记忆事件和复用记录可审计，但内容文件仍由其原生格式验证器负责。

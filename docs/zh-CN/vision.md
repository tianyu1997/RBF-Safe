# 项目愿景

> 英文原文：[Vision](../vision.md)

RBF-Safe 的目标是把机器人在线流程中重复发生的碰撞推理，转化为可检查、可复用、可持久化的配置空间几何安全知识。

## 核心思想

一次保守认证可以被规划、逆运动学、优化、审核、学习策略和执行边界共同消费，但每个消费者只能使用证书明确表达的结论。区域证书不会因为保存、传输、可视化或策略选择而自然升级。

## 设计原则

- **保守性**：只有整个区域的连杆包络与障碍物分离时才签发区域证书；
- **确定性**：相同输入产生稳定区域 ID、证书 ID、图和磁盘记录；
- **身份绑定**：机器人、场景、算法、参数和证书主题均进入摘要；
- **分层复用**：几何、分区、Atlas、规划、策略与部署层保持单向依赖；
- **失败关闭**：身份、格式、资源、时间或信任检查失败时不提供更强证据；
- **可审阅性**：证书和策略以版本化格式保存，而不是直接转储 C++ 内存。

长期定位不是单一规划器，而是机器人几何安全证书基础设施。硬件执行、真实感知、全局时间和网络共识属于外部信任边界，必须由具体部署建立。

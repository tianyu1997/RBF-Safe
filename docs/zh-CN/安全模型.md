# 安全模型（v4.7）

> 英文原文：[Safety model](../safety-model.md)

RBF-Safe 只对明确验证过的几何主题给出窄范围结论。名称中包含 `safe` 不意味着系统已经验证硬件、传感器、时钟、网络或实际执行。

## 证据等级

| 等级 | 含义 |
|---|---|
| `Unknown` | 未形成可复用的安全结论 |
| `PointChecked` | 单一配置点通过检查 |
| `CertifiedRegion` | 整个配置空间区域由保守算法认证 |
| `CertifiedConnectivity` | 指定区域或路线之间具有认证连通关系 |
| `RuntimeExecutable` | 精确命令在闭合身份、时间窗和控制器条件下获得窄范围授权 |

证据只可通过对应验证器产生。采样回归、绘图、FK、Jacobian、规划成功、签名有效或日志一致都不能单独签发 `CertifiedRegion` 或 `RuntimeExecutable`。

## 默认区域认证

默认后端是 IFK-AA + LinkIAABB。它计算配置空间 AABB 内每条连杆的保守工作空间包络；只有所有包络与所有场景障碍物分离时才签发区域证书。

证书绑定：机器人摘要、场景摘要、验证算法及版本、参数、证据等级、主题摘要、间隙下界和确定性 ID。

## 查询解释

- `contains(q) == false` 表示“当前 Atlas 未认证”，不表示“必然碰撞”；
- `nearest_region` 不认证点到区域之间的线段；
- `connected` 不生成时间参数，也不检查控制器动态；
- `TrajectoryAuditor` 的 `PARTIAL` 明确包含未认证区段；
- Safe IK 的位姿收敛是点级结果，连通路线另行证明；
- shield 的 `ACCEPT` 仍受输入证书和调用时身份约束。

## 外部信任边界

调用方负责确认机器人模型与实物一致、障碍物场景真实且及时、坐标系正确、时钟和密钥可信、控制器执行精确命令。RBF-Safe 的部署、来源和透明日志模块只能验证所提供的软件声明，不能感知物理世界。

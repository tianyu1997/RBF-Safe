# 连续时间车队占用

> 英文原文：[Continuous-time fleet occupancy](../continuous-fleet-occupancy.md)

`RBFSafe::occupancy` 从带时间戳的分段线性关节轨迹生成每条连杆的保守扫掠 AABB，并在统一离散逻辑时间线上检查机器人对。

算法对每个时间段递归细分，在对应关节区间上运行 IFK-AA 包络；部署刚体变换和显式平移/角度不确定性通过向外舍入传播。达到深度、切片或验证预算时不声明分离。

结果绑定部署、机器人、场景、时间线、工作空间坐标系、轨迹和不确定性。报告区分保守分离与潜在冲突并给出见证。

连续占用仍为非授权 `Unknown`：它不验证机器人动力学、时钟同步、轨迹跟踪或实际部署位姿。

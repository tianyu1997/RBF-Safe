# 发布流程（v5.0）

> 英文原文：[Release procedure](../../maintenance/releasing.md)

## 1. 准备

1. 更新 changelog、版本和发布日期；
2. 对齐 CMake、Python、公共版本头、CITATION 与 MoveIt package；
3. 审查 API、安全、格式、兼容性和来源；
4. 运行 `tools/check_api_surface.py`；
5. 运行 `tools/check_project_scope.py` 与
   `tools/check_documentation.py`。

## 2. 验证

- Ubuntu 22.04/24.04 的 GCC/Clang；
- Windows MSVC；
- ASan/UBSan；
- Python 3.10–3.12 wheel 安装测试；
- OMPL 与 MoveIt 2 插件测试；
- 独立 `find_package(RBFSafe)` consumer；
- 128/8192 发布基准与固定逻辑摘要；
- clang-format、Python compileall、链接和 schema fixtures。

## 3. 打包与发布

构建 sdist/wheel，检查包内容与第三方许可证，在干净环境安装并运行测试。CMake 安装到空前缀后重新构建 consumer。

只有精确测试过的提交才能合并、打 tag 和生成 GitHub release。发布说明必须列出安全语义、兼容性、迁移和已知外部边界。不要提交本地 build、缓存、输出或临时 Atlas。

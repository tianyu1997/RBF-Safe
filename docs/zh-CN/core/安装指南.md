# 安装指南（v5.0）

> 英文原文：[Installation](../../core/installation.md)

## 环境要求

- C++20 编译器：GCC、Clang 或 MSVC；
- CMake 3.23 或更高版本；
- Python 3.10–3.12 用于官方 wheel，其他版本可从源码尝试构建；
- Python 构建依赖为 `scikit-build-core` 与 `pybind11`。

核心几何、LECT 与 Atlas 不依赖 ROS、OMPL、MoveIt 或 Eigen。OMPL 和 MoveIt 2 是显式启用的可选组件。

## 从源码构建 C++

```bash
cmake -S . -B build \
  -DRBFSAFE_BUILD_TESTS=ON \
  -DRBFSAFE_BUILD_EXAMPLES=ON \
  -DRBFSAFE_BUILD_TOOLS=ON
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

安装并供下游使用：

```bash
cmake --install build --config Release --prefix install
```

```cmake
find_package(RBFSafe 5.0 REQUIRED)
target_link_libraries(app PRIVATE RBFSafe::rbfsafe)
```

需要更小依赖面时，可只链接 `RBFSafe::core`、`RBFSafe::envelope`、`RBFSafe::geometry`、`RBFSafe::lect`、`RBFSafe::atlas` 等具体目标。
使用模块级入口时，也可以链接 `RBFSafe::applications` 或
`RBFSafe::assurance`；二者只聚合已有实现 target，不增加新的运行时组件。

## Python

```bash
python -m pip install .
python -m pytest -q tests/test_python.py
```

构建 wheel：

```bash
python -m build --wheel
python -m pip install dist/rbfsafe-*.whl
```

安装后运行 `rbfsafe-inspect --help` 验证命令行入口。wheel 不包含 ROS、OMPL 或 MoveIt 插件。

## 可选组件

- OMPL：启用 `RBFSAFE_WITH_OMPL=ON`，并让 CMake 能找到 OMPL；
- MoveIt 2：在 ROS 2 Jazzy 工作空间中单独构建 `plugins/moveit2/rbfsafe_moveit`；
- 可视化：安装 `matplotlib` 或 Python extra `visualization`。

发布构建必须在独立目录中完成，不要把 CMake 缓存、wheel 解包目录或生成的 Atlas 提交到仓库。

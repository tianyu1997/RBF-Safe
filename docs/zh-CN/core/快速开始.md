# 快速开始（v5.0）

> 英文原文：[Getting started](../../core/getting-started.md)

本教程从机器人和场景 JSON 构建一个 Atlas，保存、加载并查询认证区域。成功查询只说明 Atlas 中存在相应证书；它不等于控制器获准执行。

## 1. 输入

```python
import rbfsafe

robot = rbfsafe.SerialRobotModel.from_json("data/planar_2r.json")
scene = rbfsafe.SceneSnapshot.from_json("data/empty_scene.json")
```

样本配置必须与机器人维度一致，并位于关节限制内。样本只引导 LECT 细分，不构成安全证据。

## 2. 构建 Atlas

```python
options = rbfsafe.BuildOptions()
options.maximum_depth = 24
options.maximum_nodes = 1_000_000
options.minimum_normalized_width = 1e-3
options.threads = 1

result = rbfsafe.AtlasBuilder().build(
    robot, scene, [[0.0, 0.0], [1.0, -1.0]], options
)
atlas = result.atlas
```

构建器验证两个子节点，认证节点直接成为 `SafeRegion`；未决节点只在包含输入样本时继续探索。达到深度、宽度、节点预算或取消条件时会显式停止。

## 3. 保存与加载

```python
from pathlib import Path

atlas.save(Path("atlas"))
loaded = rbfsafe.SafeAtlas.load(Path("atlas"))
loaded.verify_compatible(robot, scene)
```

加载会检查 schema、文件长度、资源上限、SHA-256 和机器人/场景身份。默认保存拒绝覆盖已有目录。

## 4. 查询

```python
q0 = [0.0, 0.0]
q1 = [1.0, -1.0]

print(loaded.contains(q0))
print(loaded.regions_at(q0))
print(loaded.nearest_region(q0))
print(loaded.connected(q0, q1))
print(loaded.route(q0, q1))
```

- `contains`：至少一个 `CertifiedRegion` 覆盖该点；
- `nearest_region`：只返回几何最近区域，不认证连接线段；
- `connected`：认证区域图中的布尔连通性；
- `route`：通过相交凸区域恢复确定性认证路线。

## 5. 运动学

```python
pose = robot.end_effector_pose(q0)
jacobian = robot.end_effector_geometric_jacobian(q0)
print(pose.position, jacobian.rows, jacobian.columns)
```

Jacobian 是点运动学结果，不是碰撞证书。

## 6. 审核、IK 与更新

```python
audit = rbfsafe.TrajectoryAuditor().audit(loaded, [q0, q1])
ik = rbfsafe.SafeIkSolver().solve(robot, scene, loaded, pose, q0)
update = rbfsafe.AtlasUpdater().update(robot, scene, scene, loaded)
```

分别阅读[轨迹审核](../atlas/轨迹审核.md)、[Safe IK](../applications/planning/安全逆运动学.md)与[动态更新](../atlas/动态更新.md)，不要把 `PARTIAL`、点位姿收敛或继承证书解释为更强结论。

## 7. 可视化

```bash
rbfsafe-inspect atlas --query 0.0 0.0
rbfsafe-inspect atlas --plot slice.png --dims 0 1
```

二维切片只呈现已存储区域，不重新执行认证。

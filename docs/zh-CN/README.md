## 阅读规则

1. 先阅读安全模型，再解释 `contains`、`connected`、审核和执行结果。
2. 中文文档说明概念、工作流和安全边界；英文文档保留逐字段规范。
3. 任何成功结果都只能表达其 `EvidenceLevel` 对应的窄范围结论。
4. 硬件状态、感知真实性、外部时钟、网络传输和控制器执行必须由调用方明确建立信任。

# 经审查部署配置

> 英文原文：[Reviewed deployment profiles](../deployment-profile-format.md)

部署配置记录几何证书无法建立的外部假设：机器人与控制器身份、计算平台、运行时构建、周期/延迟范围、监视器、传输行为、制品认证和信任检查点。

配置、角色审批和一致性评估均具有确定性 ID。审批由明确 service/key/role 签名，验证要求满足角色与 quorum 策略，并固定当前信任历史检查点。

`CONFORMANT` 表示提供的软件声明符合经审查配置，不证明硬件真实、传感器正确或控制器已经执行。部署方仍需独立建立这些事实。

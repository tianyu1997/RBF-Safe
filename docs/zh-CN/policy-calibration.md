# 策略置信度校准

> 英文原文：[Policy calibration profiles](../policy-calibration.md)

`PolicyCalibrationProfile` 保存某个精确模型、任务、数据集和方法在留出数据上的校准证据。可靠性分箱和统计下界把原始置信度映射为保守有效置信度。

配置文件包含样本数、成功数、分箱边界、观测频率、误差指标、审查元数据和确定性 ID。派生统计在加载时重新计算，不能信任文件中任意声明的汇总值。

校准后的置信度不得高于原始值；样本不足、模型/任务/数据集不匹配或输入超出配置范围时失败关闭。校准只约束策略门，不能代替 Atlas 或 shield 的几何检查。
